# 演示案例

本目录用于放置公开、脱敏的产品演示结果。

建议后续补充 3 类案例：

## 1. 日常问答

示例问题：

> 某只自选股今天为什么波动？

展示重点：

- 任务分流；
- MCP 实时取数；
- RAG 补充历史背景；
- 最终微信回复。

## 2. Deep Research

示例问题：

> 某行业涨价是否能够传导至公司利润？

展示重点：

- Research Planner；
- 结构化子任务；
- Research Loop；
- 支持 / 反方证据；
- Reviewer；
- 最终研究结论。

## 3. 自动晨报

展示重点：

- 自选股相关资讯优先；
- 市场环境；
- 产业链变化；
- 风险与失效条件；
- 微信 Bot 最终阅读效果。

> 注意：公开截图前请隐藏真实成本价、私人自选股、聊天账号、Token、内部 URL 和其他个人信息。
